  \textbf{\large Заключение}
\end{center}
\refstepcounter{chapter}
\addcontentsline{toc}{chapter}{Заключение}

В ходе выполнения дипломной работы решена актуальная задача разработки высокоточной двухотсчётной следящей системы позиционирования антенных комплексов 
для спутниковой связи.

Ключевые результаты работы представлены ниже.
\begin{itemize}

% \item Комплексный анализ датчиков углового положения для экстремальных условий эксплуатации. 
% Проведённое исследование показало преимущества индукционных датчиков (вращающихся трансформаторов) перед оптическими и магнитными энкодерами 
% по критериям устойчивости к температурным перепадам и агрессивным средам. Обоснован выбор общепромышленных синусно-косинусных ВТ типа ЛИР-ДР158А и 
% их использование в двухотсчётной схеме измерения.

\item Обоснован выбор датчиков углового положения для экстремальных условий эксплуатации. Проведённый сравнительный анализ показал 
преимущества индукционных датчиков (вращающихся трансформаторов) перед оптическими и магнитными энкодерами по  основным критериям:
  \begin{itemize}
      \item температурный диапазон работы,
      \item влагоустойчивость.
  \end{itemize}
  Экспериментально подтверждена целесообразность применения общепромышленных ВТ типа ЛИР-ДР158А в двухотсчётной схеме.

  \item Создана архитектура аппаратной платформы на базе микроконтроллера STM32F7, которая обеспечивает:
  \begin{itemize}
      \item генерацию возбуждающего сигнала (±7 В, 10 кГц) через ЦАП;
      \item синхронную оцифровку 4 каналов АЦП с частотой 10 кГц;
      \item каскадную синхронизацию таймеров, обеспечивающую точность пожачи управляющих сигналов;
      \item передачу данных по интерфейсу SSI (код Грея, 18 бит, 100 кГц).
  \end{itemize}

\item Разработано программное обеспечение следящей системы с астатизмом первого порядка. 

\item Реализована схема согласования каналов с редукцией 1:36. 

\item Проведена экспериментальная верификация системы на стенде с эталонным энкодером. 
Результаты испытаний подтвердили соответствие техническому заданию.

\end{itemize}

Практическая значимость работы заключается в создании конкурентоспособного решения для антенных систем спутниковой связи, 
превосходящего серийные аналоги ряду критериев:
\begin{itemize}
    \item cтоимость (отказ от специализированных ИС в пользу общедоступных решений),
    \item надёжность (использование ВТ),
    \item точность (±2' против ±10' у промышленных ВТ),
\end{itemize}

Кроме того, разработанная система открывает возможности для применения в смежных областях: робототехнических комплексах точного позиционирования, 
станках с ЧПУ, а также в системах наведения телескопов.

Результаты работы соответствуют мировому уровню развития техники преобразователе угол-код и вносят вклад в решение стратегической задачи обеспечения 
глобального спутникового интернет-покрытия.
